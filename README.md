# Summit University

A static website project built with HTML and CSS, created as a hands-on exercise to practice and improve front-end web development fundamentals.

## About

This project recreates a university-style website ("Summit University") as a way to get more comfortable structuring HTML pages and styling them with CSS — things like layout, navigation, images, and overall page design.

## Project Structure

```
summitUniversity/
├── Css/          # Stylesheets for the site
├── images/       # Images used across the site
└── home.html     # Main landing page
```

## Getting Started

To view the site locally:

1. Clone the repository
   ```bash
   git clone https://github.com/aarusharyal/summitUniversity.git
   ```
2. Open `home.html` in your browser.

No build tools or dependencies are required — it's a plain HTML/CSS project.
